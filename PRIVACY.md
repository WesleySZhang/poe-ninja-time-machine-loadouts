# Privacy policy

poe.ninja Time Machine Loadouts is an unofficial browser extension. It has no servers of its own and collects
nothing for its developer: no analytics, no tracking, no accounts.

## What it does with data

- **On poe.ninja character pages**, it reads the page address (league, account and character name) and asks
  poe.ninja's public builds API for that character's time machine snapshots. These are the same requests
  poe.ninja's own page makes, and they are sent without cookies.
- **When you press Generate**, and only then, it combines the snapshots you ticked into one Path of Building build
  and uploads that build to [pobb.in](https://pobb.in), a public build-sharing site. The upload is the build
  itself, which comes from poe.ninja's public data and includes the character's gear, skills and passive tree
  plus links back to the poe.ninja snapshot pages. Anyone with the resulting link can see it, under pobb.in's
  own terms.
- Nothing is saved on your computer beyond the current page, and nothing else is sent anywhere.
